# MTools 软件图标

外层橙色圆角方形，中央黄色 M，透明外部背景。通过内置 imagegen 模式生成，未调用独立 API；保留生成结果的透明通道与构图。mtools.png 为原始生成图，mtools.ico 为 Windows 多尺寸格式导出（16、24、32、48、64、128、256 px），前端使用 128 px PNG；格式导出不重新绘制。
