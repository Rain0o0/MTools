# 待实施路线与阶段验收

下列是初步建议顺序，尚未实施；按实际任务可调整。每阶段完成后从本清单移除，更新项目状态与日期记录，不长期保留已勾选待办。

## P4：长任务与复用示范

已有四项只读工具及 JSON 严格解析共享模块。后续选择确有耗时需求的工具，建立持久任务、进度、取消、资源限制、重启中断与产物清理。

验收：两个工具独立工作；依赖关系明确；一个可选工具缺失不阻断另一工具；取消/超时不虚报结果；复用没有内部跨工具导入。

## AI 副作用授权（有实际工具需求时）

当前 MCP 只开放无写入副作用的工具。新增写入、删除或外发操作前，建立软件用户授权、参数摘要绑定、过期/撤销/单次使用校验，并验证伪造、重放和参数变更不能执行。不得把当前默认拒绝误写成已支持授权执行。

## P5：首次发行整理

确定许可证、汇总传递依赖许可、完成安装器/签名与干净 Windows 机器验收，完善备份/恢复、配置升级与回退，按发行环境执行源码/桌面/Docker 成品验收，整理版本和发布产物。本机成品验收已完成，不代替首次发行验收。若实际需要远程访问或第三方插件，另立范围与 ADR 后实施。

验收：版本与源码可追溯、依赖条件透明、使用手册准确、当前问题清单真实。对外发布仅在用户授权后执行。
