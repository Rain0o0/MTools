# 编辑图片、视频和音频

在 MTools 工具目录搜索“图片”“视频”或“音频”，进入对应编辑工具。编辑工具接收用户选择的媒体源：桌面版可直接引用本机原文件，也可选择 MTools 资源库中的文件；浏览器/Docker 需将本机文件上传到服务。处理过程只读取源文件，原文件不会被覆盖，结果另存为新文件。

桌面版点“直接选择本机原文件”会打开系统文件选择器。MTools 只保存该文件的本机路径和状态快照，不会复制媒体内容；通过此 UI 引用共享给 AI 时只发送资源编号。文件移动、删除或编辑后，需重新选择；从 MTools 移除引用不会删除原文件。浏览器/Docker 无法直接访问浏览器所在电脑的磁盘，必须上传一份副本。AI 也可按下文在对话中取得路径授权后直接指定本机路径。

上传的副本默认是临时文件，通常保留 24 小时。勾选“长期保存在资源库”或之后选择“长期保存到资源库”，可将副本转为持久资源；无需再次上传。可从资源库选择现有源，也可在编辑工具里选择资源库中的叠加素材。多轨片段和字幕也可在编辑页直接上传，临时素材会在任务运行期间受到保护。资源库文件会一直保留，直到你确认移除。结果仍是新生成的副本。

## 首次使用与换电脑

打开“任务”中的“媒体组件”可查看自动检测结果，点击“重新检测”重新检查。缺失或不可用时，编辑页会直接显示原因，不必执行后才发现失败。

Windows 需要可运行的完整 FFmpeg，包含 ffmpeg.exe、ffprobe.exe 及所需编码器。可从 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html) 查找 Windows 构建；安装后将 bin 目录加入 PATH，再重新打开 MTools。便携使用时也可把两个程序及它们必需的依赖放在 MTools.exe 同级 media/ 文件夹。软件不静默下载外部程序，Windows 目录包未捆绑 FFmpeg；Docker 镜像已独立安装。仅复制一个动态版 exe、缺少配套 DLL、系统不兼容或缺少 H.264/MP3/WebP 编码器均可能检测失败；按提示安装完整构建。安装后重新连接 AI 客户端以更新工具列表。

## 图片

1. 选择 PNG/JPG/WebP 静态图片，预览旁显示实际尺寸。
2. 需要裁剪时勾选“裁剪画面”，填左侧、顶部、宽度和高度，单位像素。
3. 可旋转、填写输出宽度等比缩放，或者选择另一张图片作为水印。叠加位置相对裁剪/旋转/缩放后的画面，叠加宽度过大时调小；透明度 1 表示完全显示。
4. 选择保存格式，点击“生成图片”。完成后预览并“下载处理结果”。例如 320×240 图片裁为 160×120，左上叠加 48×32 图片，结果仍为 160×120。

## 视频

选择 MP4/MOV/MKV/WebM；输入开始、结束秒数，结束留空表示到原片结尾。可裁剪画面、选择图片水印和勾选“移除原视频声音”。点击“生成视频”，输出 MP4。起止 0.5–1.5 秒得到约 1 秒片段，受帧率精度影响。预览由系统播放能力决定，不支持的原格式仍可尝试处理为 MP4。

0.9.0 可把多项操作一次组合：

1. 点击“添加剪辑片段”，逐段填写原视频起止秒数，用上移/下移调整顺序，最多 16 段，可重复。列表为空时使用原来的单段截取；切换原文件会清空片段列表。
2. 按需裁剪画面，展开“画面与速度”设置变速、旋转、镜像、输出宽度和调色。声音同步变速并保持音调；黑白效果作用于原画面，之后添加的彩色水印保持彩色。
3. 选择水印图片，设置坐标、宽度和透明度后点击“添加此水印到组合”。重复选择可添加更多图层，共计最多 8 张。组合中的每层可设置显示起止、修改位置和透明度、下移图层或移除；列表后者在上层。还未添加到组合的上方图片也会作为全程底层水印输出。
4. 水印位置相对裁剪、旋转、镜像和缩放后的画面；显示起止相对最终成片。例如合并得到 20 秒再设 2 倍速，成片约 10 秒，显示 2–4 秒指成片的第 2–4 秒。
5. 设置主音量、淡入淡出或静音，核对输出摘要，点击一次“生成视频”。原件只读，结果另存为 MP4；片段与输出时长各不超过 1 小时，执行限时 5 分钟。

0.9.1 增加多轨与字幕：在“多轨时间线”分别添加视频、图片或音频文件，每个片段填写素材起止和放入成片的位置。视频/图片轨道按列表顺序覆盖主视频，可设置左上坐标、输出宽度和透明度；音频轨道可设独立音量，并与主音轨混合。最多添加 8 个轨道片段。图片的“素材结束”用于定义图片在成片中的显示长度。

在“字幕烧录”选择 UTF-8 的 SRT 或 WebVTT 文件。字幕时间按最终成片秒数计算；它不会跟随片段重排或倍速自动换算，建议按导出后的时间轴准备字幕。烧录需 FFmpeg 含 libass 的 `subtitles` 滤镜；Docker 包含 Noto CJK，Windows 使用本机字体。字幕与主画面的裁剪、旋转、缩放同步输出。

例如：保留原片 10–20 秒和 30–40 秒并设为 2 倍速，另加一段从成片第 2 秒开始的视频画中画、一段从第 1 秒开始的配乐、一个 Logo 和 SRT 字幕，可一次合成为约 10 秒的 MP4。轨道片段需来自当前工作区有权访问的资源；MCP 使用其 `artifact_id`。

MCP 同样只调用一次 `mtools_video_editor__edit_v1`，示例中的路径应替换为用户已明确指定的实际文件：

```json
{
  "source_path": "C:\\视频\\原片.mp4",
  "segments": [
    {"start_seconds": 10, "end_seconds": 20},
    {"start_seconds": 30, "end_seconds": 40}
  ],
  "speed": 2,
  "tracks": [
    {"artifact_id": "视频轨道资源编号", "kind": "video", "source_start_seconds": 0, "source_end_seconds": 4, "timeline_start_seconds": 2, "x": 300, "y": 100, "width": 240},
    {"artifact_id": "配乐资源编号", "kind": "audio", "source_start_seconds": 0, "source_end_seconds": 8, "timeline_start_seconds": 1, "volume": 0.35}
  ],
  "subtitle_id": "字幕资源编号",
  "rotate": 90,
  "watermarks": [
    {"source_path": "C:\\视频\\Logo.png", "width": 80, "start_seconds": 2, "end_seconds": 4},
    {"source_path": "C:\\视频\\Logo.png", "width": 60, "x": 100, "opacity": 0.5}
  ],
  "volume": 0.8,
  "fade_out_seconds": 1,
  "user_authorization": "请处理 C:\\视频\\原片.mp4，保留10–20秒和30–40秒，2倍速旋转90度，叠加指定Logo，音量0.8并淡出1秒。"
}
```

不要同时填写 `segments` 和单段 `end_seconds`；每个水印只选编号或路径。指定任意嵌套本机路径也须引用用户已明确限定文件和操作的任务原话。旧单水印 `overlay_id`/`overlay_source_path` 仍可用，嵌套素材同样受私有访问与任务清理保护。请按页面提示填写参数。

视频编码会优先使用本机实测可用的显卡，并保存检测结果，后续直接复用。无需填写额外参数；“任务 → 媒体组件”显示当前方式，处理完成的任务显示实际方式。显卡处理失败会尝试 CPU，并在结果中注明；裁剪画面、叠加和声音处理仍使用 CPU。不同编码方式的结果体积和画质可能不同。更新驱动或更换组件后可点“重新检测”；Docker 默认不映射显卡，通常使用 CPU。

## 音频

选择 MP3/WAV/FLAC/OGG/M4A；填写截取时间、主音量及淡入淡出。选择配乐/音效后可设置相对截取片段的开始位置和叠加音量；以主片段时长为准，多余部分不输出。较高音量可能失真，可先降低两轨音量。选择 MP3 或 WAV，点击“生成音频”，试听并下载。

## 等待、取消和清理

处理期间可以切换工具，到“任务”查看结果。点击“取消处理”后先显示取消中，实际终止后才显示已取消；已成功任务保留结果。软件或调度器中途退出，下次显示处理中断，需要重新选择源并创建任务，不自动重复执行。

单文件不超过 256 MiB，画面最长边不超过 4096 像素，音视频不超过 1 小时。单次处理限 5 分钟，过大文件建议缩短片段；最多 8 个任务在途，空间上限 2 GiB。任务页“清理记录与临时文件”确认后清理本工作区闲置文件，进行中的输入和已经下载的文件保留。后台服务关闭期间不执行自动清理；默认 24 小时保留期可由维护者通过 MTOOLS_MEDIA_RETENTION_HOURS 配置。

## 交给 AI

你可以让 AI 使用已共享的媒体源编号，也可以让 Codex 等本机 MCP 客户端直接指定绝对路径。路径方式不需要先在 MTools 选择/导入，也不需要再到 MTools 手动批准。

如果你当前的任务已经明确写出了要处理的本机文件路径和具体操作（例如“用 MTools 处理 `C:\视频\原片.mp4`，截取前一半并在同目录输出为 `2.mp4`”），这条任务指令本身就覆盖对应处理范围，AI 应直接调用 MTools，不应再要求你复述路径或单独回复“同意/授权”。AI 会把你指令中相关文字作为 `user_authorization` 参数引用。只有路径、操作或处理范围确实缺失、含糊或冲突时，AI 才询问缺少的信息；不得扩大到其他文件或操作。MCP 服务只收到 AI 提交的用户指令引用，无法独立验证对话，因此需要信任所选 AI 客户端遵守范围。MTools 直接读取指定本机文件，原件不复制、不覆盖；输出另存为新文件。

视频示例：如果用户已要求“截取 `C:\视频\原片.mp4` 前 30 秒并另存”，AI 无需再询问是否授权，直接调用 `mtools_video_editor__edit_v1`，参数传 `source_path`、`end_seconds: 30`，并把用户这条指令的相关原文填入 `user_authorization`。路径是 MCP 服务所在电脑的本机绝对路径；Codex 启动 `MToolsAI.exe` 时指向当前电脑。Docker MCP 的路径指容器内部，不能用它访问浏览器用户电脑的 `F:` 盘。仅接受绝对本机路径，不接受 UNC/网络路径。

路径模式示例参数：`{"source_path":"C:\\视频\\原片.mp4","end_seconds":30,"user_authorization":"请截取 C:\\视频\\原片.mp4 前 30 秒并另存。"}`。返回 `job_id` 后使用 `mtools_media_library__status_v1` 查询，完成后可用 read 分块取得文件，也可在任务页下载。

AI 可先通过只读 mtools_media_library__environment_v1 查看组件与视频加速方式；视频编辑自动选择显卡，完成后查询 Job.video_processing 确认实际编码方式和是否回退。AI 可通过 mtools_media_library__sources_v1 查看已授权媒体源。路径模式下，已明确文件和操作的用户任务指令可直接限定访问范围，编辑工具接收 source_path 和用户指令原文；路径处理不进入 MTools 批准队列。小文件也可通过 mtools_media_library__import_v1 传 name/content_base64 导入，仍需 MTools 软件逐次批准；它不适合大文件。read/jobs/status/sources 是读取操作，cancel/clear 仍需软件批准。更多 AI 使用说明见[AI 接入](../ai-interop/usage.md)。
