# 连接 AI 客户端

MTools 支持 MCP。打开软件中的“AI 助手”页面，按提示复制连接信息并添加到支持 MCP 的客户端。桌面版提供本机快捷配置；其他客户端可使用页面显示的配置。添加后按客户端提示重启或重新连接。

连接成功后，AI 可以调用与 MTools 界面相同的文本和媒体工具。需要处理本机媒体时，请在对话中明确文件和操作范围；MTools 只读原件，处理结果另存。使用共享资源编号进行写入或清理时，仍需在 MTools 界面批准。

Docker 客户端连接的是容器环境，文件路径也指容器内部。连接失败时，确认 MTools 正在运行、客户端连接配置正确，并查看 AI 助手页面的提示。
