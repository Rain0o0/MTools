# 工具箱界面使用

按 [桌面指南](../../guides/desktop.md) 打开 MTools 独立窗口，或按 [Docker 指南](../../guides/docker.md) 使用共享工作区。目录可按名称、用途和标签搜索，点击分类/标签筛选；整张工具卡片可以进入工作区，点击状态查看可用或停用原因。

按输入、参数、执行、结果的顺序使用工具。结果可复制或保存，离开前保留需要的结果；刷新或切换会清空输入和结果。使用提示可展开，版本、隐私、关于入口可点击查看说明，弹窗可用关闭或 Escape 返回。

“设置”切换浅色/深色，偏好写入应用数据目录，下次打开仍保留；保存失败时显示提示。“AI 助手”获取连接配置、查看 AI 可用范围，不要求自行填写开发配置。“任务”展示等待处理入口；当前工具立即完成，没有后台任务和历史。

连接异常时点击“重新连接”。操作会话失效保留当前输入，再次点击执行才建立新会话并重试，不自动重放。格式错误按提示修正，联系维护者时附问题编号。具体工具见 [JSON 使用](../json-formatter/usage.md)，AI 连接见 [AI 使用](../ai-interop/usage.md)。
